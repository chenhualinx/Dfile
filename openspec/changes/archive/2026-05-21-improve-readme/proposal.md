## Why

DFile is a desktop application for transferring files between Android devices and computers via MTP (Media Transfer Protocol). Despite having a bilingual (Chinese/English) UI, the project lacks a README.md to introduce the project, document its features, and guide users on how to use and build it. A well-written bilingual README will help users and contributors understand the project at a glance.

## What Changes

- Create a new `README.md` at the project root
- Write content in both Chinese and English (bilingual sections)
- Include: project overview, features list, screenshot placeholders, tech stack, prerequisites, build instructions, usage guide, and contributing guidelines
- Reference the existing i18n translations to align terminology
- Reference the Tauri and MTP configuration for accurate tech stack documentation

## Capabilities

### New Capabilities
- `readme-documentation`: A comprehensive bilingual README.md that introduces DFile, its features, build instructions, and usage guide for both users and contributors

### Modified Capabilities

## Impact

- Single new file: `README.md` at project root
- No impact on existing code, dependencies, or build process
- Documentation only
